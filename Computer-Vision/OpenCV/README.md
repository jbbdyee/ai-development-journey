# OpenCV

개인 프로젝트에서 이미지·영상 처리 기능을 구현하기 위해 진행하는 OpenCV 학습 기록입니다.

## 📚 학습 내용

### 01. Image Basic

- `cv2.imread()`로 이미지 읽기
- 이미지가 `numpy.ndarray`로 표현되는 것 확인
- `shape`를 통해 높이, 너비, 채널 확인
- 픽셀 데이터 확인

### 02. Resize / Crop

- `cv2.resize()`를 이용한 이미지 크기 변경
- `shape`와 `resize()`에서 높이·너비 순서가 다른 점 확인
- 이미지 비율을 고려하지 않고 크기를 변경했을 때 생기는 변화 확인

> 현재는 기초 학습 단계이며, 이후 이미지 자르기, 마스킹, 영상 처리 등으로 확장할 예정입니다.
