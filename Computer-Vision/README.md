# Computer Vision

개인 프로젝트에 필요한 이미지·영상 처리 기능을 구현하기 위해
Computer Vision 기초를 학습하고 작은 예제로 확인하는 공간입니다.

## 📚 현재 학습 내용

### OpenCV

- 이미지 읽기
- `ndarray`와 이미지 데이터 구조
- `shape`의 높이·너비·채널 의미
- 이미지 크기 변경
- Crop 등 기본 이미지 처리

현재는 OpenCV 기초부터 시작하고 있으며,
학습한 내용은 이후 개인 프로젝트의 이미지·영상 처리 기능에 적용할 예정입니다.

## 🎯 목표

단순히 OpenCV 함수 사용법을 외우는 것이 아니라,

- 이미지 데이터가 어떤 구조로 표현되는지 이해하고
- 기본적인 이미지·영상 처리 흐름을 직접 구현하며
- 개인 프로젝트에서 필요한 기능으로 연결하는 것

을 목표로 합니다.
