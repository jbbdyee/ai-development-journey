# Backend

백엔드 개발을 학습하며 이해한 개념과 직접 재구성한 예제를 정리합니다.

## 📚 현재 학습 내용

- [FastAPI](./FastAPI)

## 📝 앞으로 정리할 내용

새로운 백엔드 기술을 실제로 학습하고 기록할 자료가 생겼을 때 추가합니다.

예시:

- API 설계
- 애플리케이션 구조
- 테스트
- 배포
- 보안

## 🎯 목표

단순히 동작하는 기능을 만드는 데서 끝나지 않고,

- 요청과 응답이 처리되는 흐름
- 각 파일과 계층이 담당하는 역할
- 해당 구조를 사용하는 이유
- 실제 프로젝트에 적용하는 방법

을 이해하고 직접 설명할 수 있는 것을 목표로 합니다.
