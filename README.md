- 이후 더 큰 프로젝트에 적용할 수 있도록 정리하는 것

을 목표로 합니다.

## 🚀 Goal

현재는 작은 예제를 이해하고 수정해 보는 단계부터 시작합니다.

학습이 진행될수록

```text
작은 예제
    ↓
여러 파일이 연결된 예제
    ↓
미니 프로젝트
    ↓
개인 AI 프로젝트
```

순서로 발전시키며, 단순히 사용해 본 기술보다 **직접 이해하고 설명할 수 있는 기술**을 늘려가는 것을 목표로 합니다.
