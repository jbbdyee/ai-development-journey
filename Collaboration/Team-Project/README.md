# Team Project

팀 프로젝트를 진행하며 배운 협업 방식과 실제 프로젝트에 적용한 경험을 정리합니다.

단순히 프로젝트 결과물을 모으기보다,  
이전 협업에서 배운 점을 다음 프로젝트에 어떻게 적용하고 개선했는지 기록합니다.

---

## ✈️ 항공권 실시간 예매 시스템

4인 팀으로 사용자 항공권 예약, 관리자 운영 관리, AI 여행 상담 기능을 포함한 서비스를 구현했습니다.

이전 팀 프로젝트에서 **초기 계획과 작업 기준의 중요성**을 경험한 뒤 만든 범용 Plan Template을 이번 프로젝트에 실제로 적용했습니다.

프로젝트 시작 단계에서 기능 범위, 담당 영역, 완료 기준을 구체화하여 각 팀원이 공통된 기준을 바탕으로 담당 기능을 진행할 수 있도록 했습니다.

프로젝트 과정에서는 백엔드 작업뿐 아니라 구현 결과 검토, Git 브랜치 충돌 해결 지원, 필수 산출물 및 README 작성에도 참여했습니다.
